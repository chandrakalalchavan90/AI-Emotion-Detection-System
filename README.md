# AI Emotion Analytics System

## 📌 Project Overview

AI Emotion Analytics System is a real-time emotion detection project built using Python, OpenCV, DeepFace, and Streamlit.

The system detects human emotions through webcam video, analyzes confidence levels, stores emotion data in CSV format, and displays analytics using an interactive dashboard.

---

## 🚀 Features

* Real-time face detection
* Emotion detection using AI
* Confidence percentage display
* FPS (Frames Per Second) counter
* Screenshot capture
* Emotion logging in CSV
* Emotion analytics dashboard
* Pie chart visualization
* Emotion frequency graph
* Mood history analysis
* Downloadable emotion report

## ▶️ How to Run the Project

### 1️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 2️⃣ Run Emotion Detection

```bash
python main.py
```

### 3️⃣ Run Analytics Dashboard

```bash
streamlit run dashboard.py
```
